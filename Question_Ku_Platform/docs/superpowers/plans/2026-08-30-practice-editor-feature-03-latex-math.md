# 阶段 3：LaTeX 公式编辑任务计划

> 状态：已完成（2026-08-30，核心路径全通；长公式溢出检测/跨页保护未做）  
> 目标：将公式从裸 LaTeX 文本升级为可以插入、查看、点击和修改的正式编辑器节点。

## 1. 产品范围

- 行内公式：与正文在同一行显示。
- 独立公式：单独成行并居中或按设置对齐。
- LaTeX 为公式的源数据。
- KaTeX 用于编辑区和 PDF 显示。
- OMML 用于 Word 原生公式。

## 3. 本阶段不做

- 不开发完整可视化数学公式编辑器。
- 不做手写公式识别。
- 不保证 KaTeX 不支持的全部 LaTeX 宏可用。
- 不允许公式中执行任意宏或脚本。
- 不自动修正数学内容本身。

## 4. 验收标准

1. 教师可以通过按钮插入行内和独立公式。
2. 点击公式可以修改 LaTeX 并实时预览。
3. 常用公式不需要手工输入全部命令。
4. 编辑区、PDF 和 Word 都能正确显示主要公式。
5. 转换失败有明确反馈，不静默丢失。

## 5. 待确认

- 常用符号面板第一版需要覆盖哪些学科。→ 已定：数学通用 + 物理 + 少量化学；后续可按需扩充。
- 是否需要保留直接输入 `$...$` 后自动转换的快捷方式。→ 不做编辑中自动转换；保留加载时的旧文本迁移解析（避免输入干扰）。
