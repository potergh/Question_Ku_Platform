# 阶段 7：一键基本排版与导出一致性任务计划

> 状态：待真实样本共同制定规则  
> 目标：将已人工修正的内容快速整理为清晰练习，并保证预览、PDF、Word 的主要结构一致。

## 1. 一键排版原则

- 只统一样式，不擅自修改题目内容。
- 默认不改变人工确定的题目顺序。
- 默认不删除标题、自定义内容、空白和分页符。
- 默认不覆盖明确的局部格式。
- 执行前可预览变化。
- 执行后可撤销或恢复执行前状态。

## 2. 任务清单

### Task 7.1：排版规则配置

- [ ] 首版定义一个“简易练习”系统模板。
- [ ] 定义模板预设的数据结构和版本号。
- [ ] 支持将当前页面与排版设置保存为教师自定义预设。
- [ ] 支持命名、应用、重命名和删除自定义预设。
- [ ] 系统模板不可被直接覆盖，可复制后形成自定义预设。
- [ ] 定义标题、小标题、正文、选项样式。
- [ ] 定义默认题目间距。
- [ ] 定义图片默认宽度和对齐。
- [ ] 定义各题型答题留白。
- [ ] 定义选项布局阈值。
- [ ] 定义分页保护规则。

### Task 7.2：题号与小节

- [ ] 按当前版面顺序连续编号。
- [ ] 支持指定起始题号。
- [ ] 自动题型分组作为可选操作。
- [ ] 整理结构和统一样式保持两个独立命令。
- [ ] 一键排版不得改变题目顺序。
- [ ] 执行题型分组前展示变化。
- [ ] 自定义小标题默认不被自动删除。

### Task 7.3：选项自动布局

- [ ] 根据文字长度和图片判断单列、双列或四列。
- [ ] 含长公式的选项默认减少列数。
- [ ] 含图片选项采用稳定布局。
- [ ] 人工指定布局优先于自动规则。
- [ ] PDF 与 Word 使用相同布局决策结果。
- [ ] 布局结果存储下来，不在每次导出时随机变化。

### Task 7.4：图片默认规则

- [ ] 未人工设置的图片默认居中。
- [ ] 超宽图片缩放至正文宽度内。
- [ ] 小图避免无意义放大。
- [ ] 连续小图根据规则并排。
- [ ] 人工设置的尺寸、顺序和对齐不被覆盖。
- [ ] 图片与相关题干尽量保持同页。

### Task 7.5：空白与答题区域

- [ ] 按题型应用默认答题留白。
- [ ] 人工留白不被覆盖。
- [ ] 避免空白块单独占据不合理页面。
- [ ] 解答题留白跨页规则明确。
- [ ] 当前只有不含答案和解析的练习版；不同输出版本留作后续功能。

### Task 7.6：分页保护

- [ ] 避免题号单独留在页尾。
- [ ] 避免短题题干与选项分离。
- [ ] 尽量保持题干与主要图片同页。
- [ ] 尊重手动分页符。
- [ ] 尊重“从新页开始”。
- [ ] 超长题允许自然跨页，不能制造巨大空白。
- [ ] 发现无法满足的分页约束时给出提示。

### Task 7.7：执行预览与撤销

- [ ] 执行前显示将修改的项目数。
- [ ] 允许只应用部分规则。
- [ ] 保存执行前布局快照。
- [ ] 支持一次性撤销本次自动排版。
- [ ] 执行结果触发真实分页预览。
- [ ] 自动排版失败时回滚。

### Task 7.8：统一渲染适配层

- [ ] 单题富文本文档转换为统一中间结构。
- [ ] 整册内容块转换为统一中间结构。
- [ ] HTML/PDF 与 Word 从相同结构读取。
- [ ] 字体、段落、公式、图片和分页映射集中维护。
- [ ] 不在 PDF 和 Word 导出器中分别重新推断题目结构。

### Task 7.9：PDF 一致性

- [ ] 右侧预览直接来自最终 PDF。
- [ ] 公式、图片、字体和页眉页脚完整。
- [ ] 导出 PDF 使用已渲染缓存或同源重新渲染。
- [ ] 修改后缓存正确失效。
- [ ] 导出前如有未保存内容，先保存或阻止导出。

### Task 7.10：Word 一致性

- [ ] 标题、小标题、自定义内容和题目顺序一致。
- [ ] 字体、字号、对齐和行距映射正确。
- [ ] 公式为 OMML 或明确降级。
- [ ] 图片顺序、对齐和宽度正确。
- [ ] 空白和分页符正确。
- [ ] 页眉页脚正确。
- [ ] Word 保持可继续编辑。

### Task 7.11：真实样本验收

- [ ] 纯选择题练习。
- [ ] 选择、填空、计算混合练习。
- [ ] 多公式数学或物理练习。
- [ ] 多图片实验题练习。
- [ ] 三页以上练习。
- [ ] 标题、自定义说明、空白和分页混合练习。
- [ ] 逐页比较编辑器结构、PDF 预览、PDF 文件和 Word 文件。

## 3. 本阶段不做

- 不用 AI 决定题目顺序。
- 不自动修改题干或答案。
- 不追求 Word 与 PDF 像素级分页一致。
- 不做完整出版级排版引擎。
- 不对所有异常内容静默修复。
- 不输出题下答案、题下解析或独立答案册。

## 4. 验收标准

1. 一键排版前可以看到影响范围。
2. 自动排版不会破坏人工内容和明确设置。
3. 标准练习执行后只需少量人工微调。
4. PDF 与右侧预览基本一致。
5. Word 内容结构、图片和公式正确且可编辑。
6. 排版操作可撤销。

## 5. 待确认

- 选项自动分列的具体规则由哪些真实样本确定。
- 是否默认按题型自动分组。
- 未来答案功能采用题下详解、独立答案册，还是同时提供两者；当前版本均不实现。
