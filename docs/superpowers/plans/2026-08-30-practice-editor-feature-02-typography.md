# 阶段 2：字体与段落排版任务计划

> 状态：已完成（2026-08-30 验收通过）  
> 目标：建立编辑区、预览、PDF 和 Word 共用的受控排版体系。

## 1. 设计原则

- 全局样式提供清晰默认值。
- 局部格式只覆盖用户明确修改的内容。
- 字体采用白名单，避免缺失字体造成导出失真。
- 清除格式后回到当前练习默认样式。
- 一键排版不得覆盖明确的局部格式。

## 3. 本阶段不做

- 不允许任意上传字体。
- 不实现文字艺术效果。
- 不实现复杂边框、阴影和背景图案。
- 不保证任意电脑上的 Word 像素级一致。
- 不处理公式内部字体选择。

## 4. 验收标准

1. 教师能对选中文字设置字体、字号、颜色和强调。
2. 教师能设置段落对齐、缩进和行距。
3. 全局默认样式与局部格式关系明确。
4. 编辑器、PDF 和 Word 的主要文字样式一致。
5. 粘贴外部内容不会带入来源字体。

## 6. 完成记录（2026-08-30）

### 实现要点

- 令牌体系（前后端镜像）：后端 `backend/app/services/typography.py`、前端 `frontend/src/components/richeditor/typography.js`。字体白名单 7 种（宋体/黑体/楷体/仿宋/微软雅黑 + Times New Roman/Arial）、字号 12 档（初号 42 pt ~ 小五 9 pt，含中文字号名）、行距 [1, 1.25, 1.5, 1.7, 2]（1.7 为既有默认）、段前段后 [0, 3, 6, 9, 12] pt、正文颜色默认黑色 + 任意十六进制色、8 个常用快捷色。默认样式 {宋体, 五号 10.5, 1.7 倍} 与基线一致防止存量漂移。
- 样式角色：标题/小标题/总分沿用既有 `.p-title/.p-subtitle/.p-total` 固定角色样式（用户自定义预设暂缓）；题干/选项/正文统一走“练习默认样式 + 局部覆盖”。
- 中英混排与字体回退：`css_font_family()` 生成字体链恒把 Times New Roman 放最前（西文/数字优先命中），中文字体附后；Word 侧中文字体写 `w:eastAsia`、西文恒 Times New Roman。缺字体时由 CSS 字体链与 Word 本机字体确定回退（白名单外字体在保存校验即被拒绝，从源头杜绝）。
- 前端扩展：`typographyNodes.js` 的 `TextStyleExt`（fontFamily/fontSize/color 单 mark 三属性）+ `RichParagraph`（lineHeight/spaceBefore/spaceAfter/firstLineIndent/indent 段落属性）；工具栏新增字体/字号/颜色/行距/段落面板；清除格式 = clearNodes + unsetAllMarks + resetParagraph + pruneTextStyle（清掉空 span）。
- 全局默认样式：练习设置新增“默认正文样式”（字体/字号/行距），存 `page_config.default_style`（后端白名单过滤）。编辑器画布经 CSS 变量跟随；预览/导出读同一配置。局部无 marks/段落属性的内容自动跟随全局修改，已覆盖内容保持不变；段落面板提供“恢复本段为全局样式”。
- 后端渲染：预览/导出改为直接从 `rich_document` 渲染（`backend/app/services/doc_render.py` → HTML；`docx_export._add_question_from_doc` → Word），旧块路径仅作无文档回退。无排版内容保持字节级兼容（连续无属性段落合并为单个 `<div class="q-text">`，题号并入首段 `<b>`），118 项既有强断言测试全绿。
- 等价默认归一化：ProseMirror `getJSON` 会序列化全量属性默认值，`norm_para_attrs` 过滤 None/False/0/空串/`textAlign:'left'`，保证“等价默认”不算局部覆盖；保存校验对 None 值跳过。
- 列表：HTML 渲染真实 `<ul>/<ol>`（`.q-list`），Word 降级为缩进段落 + “• ”/“1. ”前缀；反向写入旧块同样降级为前缀文字行。
- 粘贴：阶段 1 的 `sanitizePastedHTML` 已剥离全部内联样式（含来源字体/字号/颜色），粘贴内容一律跟随练习默认样式。

### 验证证据

- 后端全量测试 118 项通过（新增 `test_typography.py` 8 项：令牌/白名单过滤/排版保存校验与拒绝/ marks→HTML / 等价默认 / marks→Word（东亚字体/颜色/字号/对齐）/ 全局默认样式贯通 HTML 与 Word Normal 样式）。
- 前端构建成功（约 5.3s，无错误）。
- 浏览器三轮验收：轮 1 发现严重缺陷——`updateAttributes` 只更新已有 mark 的文本，纯文本改字体/字号/颜色无效；轮 2 修复后又发现 `editor.getMarkAttributes` 非公开 API（应为 `getAttributes`）与 Element Plus 把空字符串视为无值；轮 3 全部通过：纯文本上字体/字号/颜色生效且多属性叠加同一 span、工具栏回显练习默认值、段前/段后/行距显示中文“默认”、清除格式无空 span 残留、全局默认字体保存后画布立即跟随、全程 0 console error、保存链路正常。
- 预览链路：编辑保存后预览自动刷新（网络日志 document→render 成对 200，图片加载成功）。

### 已知限制

- 缺字体回退依赖 CSS 字体链 / Word 本机字体，无显式弹窗提示（白名单校验已保证不会存入未知字体）。
- 标题/小标题为固定角色样式，暂未开放用户预设（页眉页脚阶段再议）。
- 一键排版（`layout/unify`）当前只调整旧块样式，不触碰文档 marks，天然满足“不覆盖局部格式”。
