# 练习编辑器产品决策备忘录

> 建立日期：2026-08-30  
> 用途：记录讨论中已经确认的产品决策，以及明确延期但未来需要保留扩展空间的功能。  
> 规则：本文件只记录产品决策，不代替各阶段实施计划。

## 1. 已确认的整体方向

- 题目从题库加入题目池。
- 从题目池创建练习。
- 单题编辑和整册编排是两个不同层级。
- 单题编辑一次只编辑一道题。
- 单题编辑区表现为一个“小型 Word”，题干、选项、图片和公式连续编辑。
- 整册编排负责标题、小标题、自定义内容、题目顺序、题间空白和分页。
- 使用流式块编排，不做页面任意坐标自由拖动。
- 支持自动保存，同时保留人工“保存”按钮。
- 粘贴外部内容时清理来源样式，只保留安全的基本格式。
- 右侧真实分页预览在停止编辑后延迟刷新。
- 修改练习默认不影响题库原题。
- 当前版本不做“同步修正到题库”。

## 2. 整册编排已确认决策

### 2.1 左侧内容范围

- 左侧主要显示当前练习的内容和已选题目。
- 完整题库不常驻左侧。
- 需要补题时，通过“从题库添加题目”弹窗或独立选择界面进入完整题库。

### 2.2 整册题目显示

- 整册编排画布显示接近完整的题目预览，便于教师辨认和判断版面。
- 较长内容可以采用适度折叠或性能优化，但不能只显示无法辨认的短摘要。
- 点击题目可以选中，双击或点击“编辑题目”进入单题编辑模式。
- 从单题编辑返回整册后，保留原滚动位置。

### 2.3 删除题目

- 在整册中删除题目，代表从当前练习中删除该题。
- 当前版本不引入“仅隐藏题目但保留快照”的额外状态。
- 删除前需要确认。
- 应提供撤销或短期恢复能力，具体在可靠性阶段实现。

### 2.4 题间空白

- 支持无、小、中、大四种快速选择。
- 支持自定义高度。
- 界面使用教师容易理解的预设。
- 内部使用稳定的页面单位保存，以便 PDF 和 Word 一致转换。

### 2.5 进入单题编辑

- 单击题目：选中题目并显示快捷操作。
- 双击题目或点击“编辑题目”：进入单题编辑模式。
- 编辑完成后可以返回整册编排。
- 模式切换前处理当前未保存内容。

### 2.6 标题层级

- 每份练习只允许一个主标题。
- 小标题可以有多个。
- 主标题由练习级数据管理，不作为可重复插入的普通内容块。
- 小标题作为整册内容块，可以插入、拖动、编辑、隐藏和设置样式。

### 2.7 自定义内容能力

- 教师自行插入的内容支持富文本。
- 自定义内容支持 LaTeX 公式。
- 自定义内容支持图片。
- 自定义内容与题目共用基础文字、公式和图片能力，避免维护两套编辑器。

### 2.8 题号管理

- 当前版本题号由系统管理。
- 题号不作为单题正文中的普通文字，避免被误删或重复输入。
- 整册调整题目顺序后，系统按当前规则重新计算题号。
- 后续可以提供起始题号和编号样式设置，但不允许直接在正文里编辑题号。

### 2.9 单题编辑器基础交互

- 第一版使用固定在编辑区顶部的工具栏。
- 题干和选项在视觉上连续，但选项底层使用特殊选项节点。
- 选项节点不表现为分散的后台输入框。
- 在选项中按 `Enter` 表示当前选项内换段。
- 按 `Ctrl+Enter` 或点击按钮创建下一个选项。
- 人工“保存”按钮保存当前正在编辑的题目。
- “恢复题库版本”第一版只提供整题恢复。

### 2.10 图片范围

- 第一版不提供图片说明文字。
- 支持在选项中插入必要的行内小图。
- 主要图片功能为插入、移动、缩放、替换、删除和对齐。

### 2.11 长题显示

- 整册编排画布默认完整显示题目。
- 长题允许用户手动折叠。
- 折叠只影响编辑界面，不影响分页预览、PDF 和 Word。

### 2.12 页眉页脚范围

- 第一版支持首页不同。
- 默认首页不显示页眉。
- 首页是否显示页码作为设置项。
- 第一版页眉页脚不支持学校 Logo，只支持文字和动态变量。

### 2.13 四学科基线

- 阶段 0 基线覆盖物理、数学、化学和英语。
- 物理作为主样本，数学、化学和英语至少各选一份代表性练习。

### 2.14 子页面刷新问题

- 当前本地系统存在子页面刷新后页面丢失或无法继续访问的问题。
- 用户必须重新进入 `http://localhost:8000` 才能恢复。
- 该问题属于基础路由可靠性问题，提升为阶段 0 阻塞项，不等待阶段 8。
- 修复后刷新练习列表、题目池和练习编辑器等子页面时，应保持当前路由和练习参数。

### 2.15 旧练习迁移

- 旧练习需要迁移到新编辑文档结构。
- 采用一次性批量迁移，不要求用户逐份手动转换。
- 执行迁移前备份数据库和相关练习资产。
- 迁移工具必须支持预检查和试运行报告。
- 迁移过程必须可重复执行，不能重复生成题干、选项、图片或内容块。
- 旧字段和旧内容块在迁移稳定前继续保留，不立即删除或覆盖。
- 单份练习迁移失败时标记失败原因，不阻断其他练习迁移。
- 迁移成功的旧练习统一使用新编辑器打开。
- 迁移失败的旧练习保留原始数据，修复后可以重新迁移。

### 2.16 默认字体与文字设置

- 默认中文正文字体为宋体。
- 字号同时显示中文名称和磅值，例如“小四（12 pt）”。
- 文字颜色允许任意选择，不限制为固定调色板。
- 界面仍应提供常用颜色，减少重复选择成本。

### 2.17 公式编辑与降级

- 公式采用弹窗编辑。
- 弹窗包含 LaTeX 输入和实时公式预览。
- Word 原生公式转换失败时，降级为公式图片以保证显示。
- 发生降级时必须向用户显示导出警告。

### 2.18 多图片布局

- 连续多张小图默认自动并排。
- 教师可以人工移动图片、调整顺序或改为纵向排列。
- 第一版不做图片裁切。

### 2.19 页面方向

- 第一版支持 A4 纵向和 A4 横向。
- 第一版不做奇偶页不同的页眉页脚。

### 2.20 一键排版与模板

- 一键排版指页面和版面样式整理，不修改题目内容。
- 一键排版不改变题目顺序。
- 按题型重新分组是独立功能，执行前需要确认。
- 首版只内置一个“简易练习”模板。
- 模板体系支持保存教师自定义预设。
- 后续可以增加更多系统模板，不在首版一次完成。

### 2.21 本地草稿恢复

- 需要浏览器本地草稿恢复。
- 自动保存提交前的最新修改保存在本地。
- 浏览器异常关闭、页面意外刷新或服务中断后，再次进入时提示恢复。
- 本地草稿恢复不代替正常后端保存。

## 3. 当前版本不做答案和解析

### 3.1 当前决定

- 当前练习制作版本不展示答案。
- 当前练习制作版本不展示解析。
- 单题编辑器不提供答案和解析编辑区。
- 整册编排器不提供答案块或解析块。
- 当前 PDF 和 Word 只输出练习题目及必要的答题空白。
- 暂不区分学生版和教师版。

原因：当前练习系统与题库答案、解析数据相对分离，优先完成题目内容编辑、整体编排和稳定导出，避免过早扩大范围。

### 3.2 当前实现约束

- 旧数据中即使存在答案和解析，也不在当前练习编辑器中显示。
- 当前重构不得因为不使用答案和解析而删除题库或旧练习中的原始答案数据。
- 新的数据结构应预留后续关联答案与解析的能力。
- 当前导出器应明确按“仅练习正文”模式工作。
- 不在单题正文中用普通文字伪装答案或解析字段。

## 4. 未来答案与解析的两种形态

答案和解析作为后续独立功能设计，至少支持以下两种输出形态。

### 4.1 题目下方模式

答案和解析紧跟对应题目显示：

```text
第 1 题……

答案：……
解析：……
```

适用场景：

- 教师备课。
- 例题讲解。
- 逐题订正。
- 教师详解版。

未来需要考虑：

- 只显示答案或同时显示解析。
- 答案和解析样式。
- 是否默认折叠。
- 题目与解析是否尽量保持同页。

### 4.2 独立答案册模式

题目正文只显示练习，答案和解析单独编排：

```text
练习正文
  第 1 题
  第 2 题
  第 3 题

答案与解析册
  第 1 题答案与解析
  第 2 题答案与解析
  第 3 题答案与解析
```

未来可以进一步决定：

- 答案册附在练习文末。
- 答案册导出为单独的 Word/PDF 文件。
- 只输出答案，或输出答案加解析。
- 答案册是否使用独立页眉页脚和标题。

### 4.3 未来建议的输出模式

后续可以形成三个明确模式：

1. **练习版**：只有题目和答题空白。
2. **题下详解版**：每题后显示答案和解析。
3. **独立答案册版**：练习正文与答案解析分开编排或分文件导出。

以上三种模式当前只作产品备忘，不进入现阶段开发任务。
