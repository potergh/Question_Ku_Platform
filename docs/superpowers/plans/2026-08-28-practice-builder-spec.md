# 练习制作系统产品规格草案

> 日期：2026-08-28  
> 状态：关键决策已确认（2026-08-28），待冻结 V1 边界后进入实施拆分  
> 产品基础：复用现有题库的题目内容、学科、题型、难度和标签体系

## 1. 产品定义

本阶段开发一个面向教师的练习制作系统。

教师从完整题库中按学段、年级、科目、难度、题型和知识点标签筛选题目，形成一个临时选题池；随后将选中的题目加入练习编辑器，在不直接破坏题库原题的前提下完成人工纠错、内容调整、图片排布和基础排版；最后通过页面预览确认效果，并导出 Word 或 PDF。

核心链路：

```text
题库筛选
  ↓
临时选题池
  ↓
创建练习草稿
  ↓
人工纠错与块式排版
  ↓
一键基本排版
  ↓
页面预览
  ↓
导出 Word / PDF
```

第一版的核心产物是“练习”，暂不以包含完整知识讲解的复杂讲义为目标，也暂不做类似 Word 的自由画布编辑器。

## 2. 已确认的产品决策

1. 第一版重点制作练习。
2. 使用者包括本人和其他教师。
3. 选题结果先进入临时选题池。
4. 编辑器采用块式编辑，不做页面内任意坐标拖动的自由画布。
5. 图片支持调整顺序、相对位置、对齐方式和大小。
6. 支持 Word 和 PDF 导出。
7. 导出前必须提供页面预览。
8. 现有题库中可能存在 OCR 错误和排版问题，人工整理工作主要放在练习编辑阶段完成。

## 3. 产品边界

### 3.1 第一版包含

- 题库多条件筛选。
- 临时选题池。
- 从选题池创建练习。
- 练习结构编排。
- 题目内容副本编辑。
- 题内文字、图片、选项等内容块调整。
- 一键基本排版。
- A4 分页预览。
- Word 导出。
- PDF 导出。

### 3.2 第一版暂不包含

- 类似 Word 的页面自由画布。
- 图片在页面任意坐标拖动。
- 复杂文字环绕图片。
- 多人同时编辑同一份练习。
- 审批流、评论流和复杂权限系统。
- PDF 与 Word 像素级完全一致。
- 在线答题、自动批改和学生成绩分析。
- 完整知识讲义、课程教案等复杂内容生产。

## 4. 信息结构

系统分为三个主要工作区：

```text
完整题库
  └── 负责发现和选择题目

临时选题池
  └── 负责整理本次可能使用的题目

练习编辑器
  └── 负责内容纠错、结构编排、排版、预览和导出
```

基本原则：

- 选题池负责“选什么”。
- 练习编辑器负责“怎么呈现”。
- 题库原题是长期数据。
- 练习中的题目是当前练习的可编辑副本。

## 5. 题库筛选

### 5.1 筛选维度

建议将稳定属性和业务标签区分开：

| 类型 | 字段 | 示例 |
|---|---|---|
| 稳定属性 | 学段 | 初中 |
| 稳定属性 | 年级 | 七年级、八年级、九年级 |
| 稳定属性 | 科目 | 物理、化学、数学、英语 |
| 稳定属性 | 题型 | 选择题、填空题、实验题、计算题 |
| 稳定属性 | 难度 | 1-5 |
| 业务标签 | 知识点 | 液体压强、欧姆定律 |
| 业务标签 | 能力或错因 | 图像分析、单位换算、易错题 |

学段、年级、科目、题型和难度建议采用正式字段；知识点、能力和错因采用标签。这样可以避免所有维度都堆入标签后造成筛选规则混乱。

### 5.2 筛选能力

- 多条件组合筛选。
- 关键词搜索。
- 按题型查看。
- 按难度查看。
- 按一个或多个标签查看。
- 按来源试卷查看。
- 筛选有答案或有解析的题目。
- 筛选已人工审核的题目。
- 显示当前条件下的题目数量。
- 手动勾选题目加入选题池。

### 5.3 可选的辅助选题能力

以下能力建议纳入 V1 或紧随 V1 实现：

- 从当前筛选结果随机抽取指定数量。
- 按题型指定数量抽取。
- 按难度比例抽取。
- 将某道题替换为同学科、同题型、相近难度和相同标签的题目。

相似题检测和自动去重不作为第一版必需能力。

## 6. 临时选题池

### 6.1 定位

临时选题池相当于从完整题库中抽出的一个小题库。它保留题库的基本查看和筛选能力，但只服务于当前练习制作过程。

### 6.2 功能

- 加入题目。
- 批量加入题目。
- 移除题目。
- 批量移除题目。
- 按题型、难度和标签二次筛选。
- 查看当前题目总数及各题型数量。
- 调整题目初始顺序。
- 继续回到完整题库补选。
- 将全部或部分题目加入练习。
- 清空选题池。

### 6.3 暂存策略建议

- 选题池保存在数据库中，不只保存在浏览器内存中。
- 刷新页面、退出系统或关闭浏览器后不丢失。
- 第一版只保留一个当前选题池，不做多个长期命名题篮。
- 创建练习后，询问是否清空选题池。
- 用户主动清空时需要确认。

该策略仍需产品确认，详见“待确认决策”。

## 7. 练习与题库原题的关系

### 7.1 题目快照

题目加入练习时，系统创建当前题目的练习快照。练习编辑器修改快照，而不是直接修改题库原题。

```text
题库原题
  ↓ 加入练习
练习题目快照
  ↓
修改题干、选项、图片、答案、解析和排版
```

这样可以满足以下目标：

- 老师可针对当前练习自由修正 OCR 错误。
- 同一道题在不同练习中可以有不同表述和排版。
- 已导出的旧练习不会因题库更新而改变。
- 避免误操作破坏题库长期数据。

### 7.2 已确认的操作范围（决策 3）

- 保存到当前练习。
- 恢复为加入练习时的题库版本。
- 显示“当前练习版本已相对题库修改”。
- **不提供“同步回题库”**：练习中的修改永远不写回题库原题，题库只能通过题库页自身编辑。

## 8. 练习编辑器

### 8.1 编辑器形态

采用块式编辑器。页面建议分为三个区域：

```text
┌────────────┬──────────────────────┬────────────────┐
│ 练习结构树 │ 块式内容编辑区       │ A4 页面预览    │
│            │                      │                │
│ 选择题     │ 题干、图片、选项     │ 第 1 页        │
│ 填空题     │ 拖动、编辑、缩放     │ 第 2 页        │
└────────────┴──────────────────────┴────────────────┘
```

在窗口宽度不足时，预览区可以切换为独立标签页或全屏模式。

### 8.2 练习级内容块

- 练习标题。
- 副标题。
- 学生姓名、班级、日期等信息栏。
- 题型小节标题。
- 普通说明文字。
- 题目。
- 分页符。
- 集中答案区（V1 不做，题库无答案，留待后续）。

### 8.3 题目内部内容块

一道题建议拆成以下可排序内容块：

```text
题目
├── 题干文字块
├── 图片块
├── 补充文字块
├── 选项块
├── 答题留白块
├── 答案块
└── 解析块
```

块式模型需要支持同一题内多段文字和多张图片交错排列。例如：

```text
题干第一段
图片 2
题干第二段
图片 1
选项
```

### 8.4 内容纠错能力

- 修改题干。
- 修改选项标签和选项内容。
- 增删选项。
- 修改答案。
- 修改解析。
- 修改题型。
- 修正公式和特殊符号。
- 删除错误文字。
- 补充遗漏文字。
- 将一段题干拆成多个文字块。
- 合并相邻文字块。
- 恢复题库原始内容。

### 8.5 题目与结构编排

- 调整题目顺序。
- 按题型自动分节。
- 将题目拖到其他小节。
- 新增、修改和删除自定义小节。
- 设置是否显示小节标题。
- 设置是否显示题号。
- 自动连续编号。
- 手动指定起始题号。
- 插入分页符。
- 设置题目从新页开始。
- 设置题目尽量保持在同一页。

### 8.6 图片操作

第一版支持：

- 图片块上移和下移。
- 图片插入到指定文字块之前或之后。
- 多张图片调整顺序。
- 左对齐、居中和右对齐。
- 预设宽度和自定义宽度。
- 保持图片纵横比。
- 删除不需要的图片。
- 恢复原始图片设置。

第一版暂不支持：

- 图片在纸张任意坐标拖动。
- 图片浮动和复杂文字环绕。
- 在系统内进行复杂图片编辑。

## 9. 一键基本排版

### 9.1 功能目标

一键基本排版用于快速统一练习的基础样式和分页规则，不替代老师的内容判断。

### 9.2 默认规则

- 按当前题目顺序连续编号。
- 按题型生成小节标题。
- 统一字体、字号和行距。
- 统一题目之间的间距。
- 图片默认居中。
- 图片宽度不超过正文区域。
- 多张图片保留人工调整后的顺序。
- 选择题选项根据内容长度自动选择一列、两列或四列。
- 填空题和解答题按规则添加答题留白。
- 避免题号单独出现在页尾。
- 尽可能避免题干和主要图片跨页分离。
- 尽可能避免选项被不合理拆页。

### 9.3 核心约束

自动排版不得覆盖用户已经明确设置的内容顺序、图片顺序、图片位置、分页符和单题特殊设置。

建议将操作拆成两个命令：

1. **整理结构**：可以按题型重新分组或调整结构，执行前展示变化并要求确认。
2. **统一排版**：只处理编号、字体、图片尺寸、间距、选项布局和分页，不改变题目顺序。

## 10. 预览

### 10.1 预览能力

- A4 纸张比例。
- 显示真实分页边界。
- 显示当前页和总页数。
- 缩放查看。
- 全屏预览。
- 编辑后自动或手动刷新。
- 导出 PDF 前预览。
- 导出 Word 前使用同一内容模型预览。
- （学生/教师版切换预览：V1 不做，仅学生版，见决策 2）

### 10.2 一致性要求

- PDF 应与网页预览基本一致。
- Word 应保证内容结构、图片顺序和基础样式一致。
- 不承诺 Word 在不同电脑、字体环境和 Word 版本中与网页预览像素级一致。
- Word 打开后应允许教师继续编辑。

## 11. 导出

### 11.1 格式

- `.pdf`
- `.docx`

### 11.2 版本（决策 2 已确认）

- **V1 只输出学生版**：题目和答题留白，不显示答案与解析。
- 原因：当前题库不带答案，教师版无实际内容可显示。
- 教师版与文末集中答案版留待题库补充答案后再做；数据模型保留 answer/explanation 快照字段，内容通常为空。

### 11.3 基本导出设置

- 文件名。
- 纸张大小，第一版默认 A4。
- 页面方向，默认纵向。
- 页边距预设。
- 是否显示页码。
- 是否显示学生信息栏。
- 是否显示分值。
- 是否显示总分。
- （答案显示方式：V1 不做，仅学生版）

## 14. 第一版验收场景

### 场景一：筛选并建立选题池

1. 教师进入题库。
2. 选择初中、九年级、物理、中等难度和“液体压强”标签。
3. 在结果中选择若干选择题和填空题。
4. 将题目加入临时选题池。
5. 刷新页面后选题池内容仍存在。
6. 在选题池中移除一题并补选一题。

### 场景二：创建并编辑练习

1. 从选题池创建练习草稿。
2. 系统为每道题创建独立快照。
3. 系统按题型生成小节。
4. 教师修正一道题的 OCR 错字。
5. 教师修改一个选项。
6. 教师将一张图片移动到题干第二段之后。
7. 教师缩小图片并设置居中。
8. 教师调整题目顺序和解答题留白。
9. 题库原题不因上述操作自动改变。

### 场景三：排版、预览和导出

1. 教师执行统一排版。
2. 系统统一编号、字体、图片尺寸、选项布局和题目间距。
3. 人工调整过的图片顺序和分页符保持不变。
4. 教师在 A4 预览中检查分页。
5. 教师切换学生版和教师版预览。
6. 成功导出 Word。
7. 成功导出 PDF。
8. PDF 与预览基本一致。
9. Word 中的内容、图片顺序和基础样式正确，并可继续编辑。

## 15. 决策记录（2026-08-28 确认）

以下决策已由产品确认，规格可进入冻结和实施拆分阶段。

### 决策 1：其他教师的使用方式 → **不做账号系统**

V1 不提供登录和多用户，`SelectionBasket.owner_id` 等字段留空。其他教师通过导出的 Word/PDF 使用成果。

### 决策 2：输出版本 → **仅学生版**

当前题库不带答案，教师版无实际内容。教师版/文末答案版留待题库补充答案后再做。

### 决策 3：练习修正同步回题库 → **不做**

练习快照的修改永远不写回题库原题。题库数据只能通过题库页自身编辑。
这保证了练习系统对题库零侵入。

### 决策 4：题型分组规则 → **按建议方案**

默认按题型自动分组，允许修改小节名称、拖动题目跨小节、新增自定义小节和关闭分组。

### 决策 5：分值 → **可选能力**

保留单题分值和总分能力，默认不显示，需要时切换到试卷式显示。

### 决策 6：答题留白 → **按建议方案**

支持无留白、小、中、大和自定义行数；默认值由题型决定，允许单题覆盖。

### 决策 7：选题池清空规则 → **按建议方案**

刷新和退出不清空；创建练习后询问是否清空；手动清空需要确认。
