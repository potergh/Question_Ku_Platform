# 阶段 8：体验与可靠性优化任务计划

> 状态：待前序阶段完成后实施  
> 目标：让教师能够稳定、连续地使用练习编辑器完成日常工作。

## 1. 任务清单

### Task 8.1：快捷键

- [ ] Ctrl+S 手动保存。
- [ ] Ctrl+Z / Ctrl+Y 撤销重做。
- [ ] 常用文字格式快捷键。
- [ ] 图片和内容块键盘移动。
- [ ] 快捷键说明面板。
- [ ] 避免与浏览器快捷键产生危险冲突。

### Task 8.2：保存可靠性

- [ ] 网络或后端暂时失败时保留本地未保存内容。
- [ ] 保存重试和指数退避。
- [ ] 防止并发请求覆盖新内容。
- [ ] 切题和关闭页面保护。
- [ ] 将尚未完成后端保存的最新编辑内容写入浏览器本地草稿。
- [ ] 浏览器异常关闭、页面意外刷新或服务中断后保留草稿。
- [ ] 再次进入同一练习或题目时提示恢复本地草稿。
- [ ] 用户可以选择恢复、放弃或稍后处理。
- [ ] 后端保存成功后清理对应的过期本地草稿。
- [ ] 本地草稿包含练习 ID、题目 ID、文档版本和更新时间，避免恢复到错误题目。
- [ ] 清楚显示最近保存时间。

### Task 8.3：撤销与版本保护

- [ ] 单题编辑撤销栈。
- [ ] 整册编排撤销栈。
- [ ] 自动排版前快照。
- [ ] 恢复题库版本前快照。
- [ ] 关键破坏性操作二次确认。
- [ ] 可选保留有限数量的历史版本。

### Task 8.4：性能

- [ ] 50 道题以上整册画布性能。
- [ ] 大图片延迟加载。
- [ ] 右侧预览防抖和缓存。
- [ ] 只在必要时重新渲染 PDF。
- [ ] 切换题目时避免重复加载全部练习。
- [ ] 长公式和大量公式性能。

### Task 8.5：异常内容处理

- [ ] 空题干。
- [ ] 无选项或选项不完整。
- [ ] 重复选项标签。
- [ ] 损坏或缺失图片。
- [ ] 无法渲染的 LaTeX。
- [ ] 超宽内容。
- [ ] 超高图片或不可分页块。
- [ ] 导出失败的定位信息。

### Task 8.6：交互提示

- [ ] 首次进入整册编排的简短引导。
- [ ] 首次进入单题编辑的简短引导。
- [ ] 自动保存状态清晰但不打扰。
- [ ] 空状态提供下一步操作。
- [ ] 危险操作提示后果。
- [ ] 错误信息使用教师能理解的语言。

### Task 8.7：可访问性与易用性

- [ ] 所有主要按钮有文字或提示。
- [ ] 键盘可以完成主要操作。
- [ ] 拖动操作有按钮替代方式。
- [ ] 颜色不是唯一状态提示。
- [ ] 适当的焦点状态。
- [ ] 缩放后工具栏仍可用。

### Task 8.8：导出前检查

- [ ] 未保存内容检查。
- [ ] 缺失图片检查。
- [ ] 公式错误检查。
- [ ] 空题检查。
- [ ] 题号连续性检查。
- [ ] 页眉页脚变量检查。
- [ ] 导出问题列表可定位到具体题目。

### Task 8.9：全流程回归

- [ ] 题库筛选到题目池。
- [ ] 题目池创建练习。
- [ ] 整册内容编排。
- [ ] 单题富文本编辑。
- [ ] 公式和图片编辑。
- [ ] 页面与页眉页脚设置。
- [ ] 一键排版。
- [ ] 预览。
- [ ] Word/PDF 导出。
- [ ] 旧练习兼容。
- [ ] 所有主要子页面直接访问和浏览器刷新。
- [ ] 刷新练习编辑器后保留当前练习 ID 和路由状态。

### Task 8.10：用户验收

- [ ] 使用真实备课任务制作至少三份练习。
- [ ] 记录完成时间和人工修正次数。
- [ ] 记录最常见的卡点。
- [ ] 记录一键排版后仍需修改的项目。
- [ ] 由至少一位其他教师试用。
- [ ] 根据反馈区分阻塞问题和后续增强。

## 2. 本阶段不做

- 不无边界扩充新功能。
- 不在稳定性验收阶段重构核心数据模型。
- 不因个别样本增加无法复用的特殊规则。
- 不在没有用户验证时增加复杂协作功能。

## 3. 验收标准

1. 完整制作一份练习时无数据丢失。
2. 保存失败和导出失败都有可理解、可恢复的反馈。
3. 50 道题规模下仍可正常编辑。
4. 至少三套真实练习成功导出 Word/PDF。
5. 其他教师无需开发人员指导即可完成基本流程。

## 4. 待确认

- 第一轮试用教师人数。
- 哪三类真实练习作为最终验收样本。
