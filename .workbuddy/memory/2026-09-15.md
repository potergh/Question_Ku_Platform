### 技能订正

### 顺手记下的工具坑

- **PowerShell 的 stdout 在本沙箱里被吞**：`Get-Process | Select ...`、`Get-CimInstance ... | Format-List`
  直接返回 exit 0 但**零输出**。必须 `| Set-Content <文件>` 再用 Read 读。
- `tasklist //FI "IMAGENAME eq python.exe"` 报「无效参数/选项 - '//FI'」——Git Bash 的 MSYS 路径转换
  把参数吃了。用 `tasklist | grep -i python` 替代。
- **`taskkill //PID <pid> //F` 同样会被 MSYS 吃掉**（报「无效参数/选项 - '//PID'」）。
  改用 PowerShell `Stop-Process -Id <pid> -Force -ErrorAction SilentlyContinue`，
  或加 `MSYS_NO_PATHCONV=1`。杀完用 Bash 的 `netstat`/`tasklist` 复核（PowerShell stdout 读不到）。

**一个值得记的推断**：用户看到 UI 上「一直有个后台任务在运行」，很可能就是这些**没结束的 Bash 工具调用**——
服务不退，起它的那次调用就永远不返回，任务条目就一直显示运行中。杀完 node，bash 随即退出，任务理应消失。
（这条是推断：UI 任务面板我读不到，只能从进程因果链倒推。）

**对天机阁的影响 = 只有本地预览入口消失**。ECS（`101.43.69.246:3000`）与沙箱域名是独立实例，
源码与全部数据文件（`index.html` / `server.js` / `secrets.json` / `hist/` / `users.json` /
`rate.json` / `sync_data.*.json`）都在磁盘上，杀进程不碰。且 `server.js` 的 8 处写盘**全是同步即时写**
（`fs.writeFileSync` / `writeFileAtomic`），无 debounce / 延迟落盘 → **没有未落盘的内存态，零数据损失**。
