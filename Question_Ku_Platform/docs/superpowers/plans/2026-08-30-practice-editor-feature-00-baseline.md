# 阶段 0：现状基线与兼容保护任务计划

> 状态：已完成（阶段 1 已在此基础上实施）  
> 目标：在重构练习编辑器前，固定现有数据、预览和导出行为，确保后续功能可以安全迭代。

## 1. 阶段产物

- 一套覆盖真实题目的编辑与导出基线样本。
- 一份旧内容块到新文档结构的迁移规则。
- 一组自动化回归测试。
- 一份人工视觉验收清单。
- 可验证、可重试、可回退的迁移方案。

## 2. 任务清单

### Task 0.1：盘点现有练习数据

- [ ] 统计练习、章节、题目快照和内容块数量。
- [ ] 统计各类内容块：text、options、image、answer_space、answer、explanation。
- [ ] 找出空内容、损坏图片、异常选项和无法解析的 LaTeX。
- [ ] 找出已经人工修改过的练习题。
- [ ] 记录当前数据库迁移版本。
- [ ] 禁止在盘点过程中修改用户数据。

### Task 0.2：建立基线练习样本

- [ ] 建立一份物理主基线，覆盖文字、公式、单图、多图、选项图和混合题型。
- [ ] 建立至少一份数学代表性练习，重点覆盖复杂公式。
- [ ] 建立至少一份化学代表性练习，重点覆盖上下标、方程式和实验图。
- [ ] 建立至少一份英语代表性练习，重点覆盖长文本和题组。
- [ ] 至少一份基线练习达到三页以上。
- [ ] 包含标题、副标题、信息栏、分值、留白和分页。
- [ ] 保存每份样本的 PDF、Word 和分页预览截图。
- [ ] 样本文件使用固定名称，作为后续阶段回归输入。

### Task 0.3：固定当前 API 与行为

- [ ] 测试练习列表和练习详情。
- [ ] 测试从题库继续添加题目。
- [ ] 测试章节增删改和排序。
- [ ] 测试题目移动、删除和恢复题库版本。
- [ ] 测试内容块增删改和排序。
- [ ] 测试一键整理结构。
- [ ] 测试当前统一排版。
- [ ] 测试分页预览、PDF 和 Word 导出。

### Task 0.4：设计兼容数据模型

- [ ] 定义新富文本文档字段，不直接覆盖旧字段。
- [ ] 明确旧 `content_snapshot`、`options_snapshot` 和内容块的保留期限。
- [ ] 定义新文档版本号。
- [ ] 定义一次性批量迁移状态和文档版本号。
- [ ] 旧字段在迁移稳定前保持原样，支持回退读取。
- [ ] 新编辑器迁移后只写新文档字段，不反向破坏旧字段。
- [ ] 新数据写入失败时不得破坏旧内容。

### Task 0.5：实现旧练习迁移

- [ ] 迁移前自动备份数据库和练习资产目录。
- [ ] 提供只检查不写入的试运行模式。
- [ ] 试运行报告列出练习数量、题目数量、内容块数量、异常图片和异常公式。
- [ ] 题干文字转换为新文档段落节点。
- [ ] `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 转换为公式节点或安全保留原文。
- [ ] `options_snapshot` 转换为视觉连续的特殊选项节点。
- [ ] Markdown 图片和旧 image 内容块转换为图片节点。
- [ ] 保留图片顺序、对齐和宽度。
- [ ] 留白块转换为明确的答题留白或版面空白节点。
- [ ] 无法识别的内容保留原文并记录警告。
- [ ] 单份失败不回滚其他成功练习。
- [ ] 迁移脚本可重复运行，不重复生成节点。
- [ ] 迁移结果记录成功、警告和失败状态。

### Task 0.6：增加迁移回归测试

- [ ] 迁移前后练习、章节和题目数量一致。
- [ ] 题干、选项和图片数量不减少。
- [ ] 迁移前后题目顺序一致。
- [ ] 重复执行迁移不产生重复节点。
- [ ] 单份异常练习不阻断其他练习。
- [ ] 迁移失败练习保留旧数据并可重试。
- [ ] 迁移后的旧练习可以打开、编辑、预览和导出。
- [ ] 新练习直接使用新文档结构创建。
- [ ] 数据库结构升级和代码回退路径经过验证。

### Task 0.7：视觉基线验收

- [ ] 对每份基线样本逐页检查。
- [ ] 检查题号、题干、选项、图片、公式和留白。
- [ ] 检查是否发生漏题、重复题和内容错序。
- [ ] 记录现有已知排版问题，不要求本阶段修复。
- [ ] 后续阶段必须说明基线差异是修复、预期变化还是回归。

### Task 0.8：修复子页面刷新与直接访问

- [ ] 复现从 `http://localhost:8000` 进入练习编辑器后刷新页面丢失的问题。
- [ ] 检查 Vue History 路由与 FastAPI 静态文件回退规则。
- [ ] 确保题库、题目池、练习列表和练习编辑器子路由可以直接访问。
- [ ] 刷新练习编辑器时保留 URL 中的练习 ID 和当前页面。
- [ ] 未知前端路径返回前端入口，由前端显示 404；不得误吞 `/api` 路由。
- [ ] 开发模式和 `localhost:8000` 生产静态模式都要验证。
- [ ] 为关键子路由增加刷新回归测试或自动冒烟测试。

## 3. 明确不做

- 不引入富文本编辑器。
- 不改变当前用户界面。
- 不修复所有旧排版问题。
- 不删除旧数据字段。
- 不做题库同步。

## 4. 阶段完成标准

- 自动化测试通过。
- 基线练习可以正常打开、预览、导出。
- 旧数据迁移规则已经文档化并有测试覆盖。
- 有明确的回退路径。
- 用户确认可以开始编辑器重构。

## 5. 待确认

- 真实旧数据中出现无法自动判断的内容时，采用保留原文并标记，还是阻止该练习迁移；建议保留原文并标记。
