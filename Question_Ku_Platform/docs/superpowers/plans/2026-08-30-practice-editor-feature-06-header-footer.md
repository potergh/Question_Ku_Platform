# 阶段 6：页面样式、页眉与页脚任务计划

> 状态：已确认（2026-08-31）
> 目标：补齐正式打印练习所需的页面级设置，并在预览、PDF 和 Word 中保持一致。

## 0. 已确认决策（2026-08-31 用户拍板）

1. `{date}` 变量：使用**导出当天日期**。
2. 变量集合：`{title}` `{subject}` `{grade}` `{date}` `{page}` `{total}`，另加可选 `{school}`（学校）`{teacher}`（教师）；所有变量均可选，未填写则替换为空。
3. 默认模板：**标题页眉 + 居中页码**（header.center=`{title}`、footer.center=`{page} / {total}`）。
4. 学生信息栏/分值/总分显示：**本阶段不做**（沿用现有设置，信息栏扩展留待后续）。
5. 首页不同：支持「首页隐藏页眉/页脚」，PDF 用 pymupdf 覆盖首页页眉页脚区域实现，Word 用 `different_first_page_header_footer` 实现。
6. 纸张：A4 纵向/横向；页边距保留 narrow/normal/wide 预设 + 新增自定义（上/下/左/右 mm）。
7. 页眉页脚编辑：设置面板三栏输入 + 变量插入菜单 + 常用模板套用 + 首页不同开关 + 分隔线开关；不做页内直接双击编辑。

## 1. 任务清单

### Task 6.1：页面配置模型

- [ ] 纸张大小，第一版至少支持 A4。
- [ ] 支持 A4 纵向和 A4 横向。
- [ ] 上、下、左、右页边距。
- [ ] 全局正文字体、字号和行距。
- [ ] 信息栏显示设置。
- [ ] 分值和总分显示设置。
- [ ] 页面配置版本号和默认值。

### Task 6.2：页面设置界面

- [ ] 提供常用页边距预设。
- [ ] 提供自定义页边距。
- [ ] 提供纸张方向。
- [ ] 提供全局字体、字号和行距。
- [ ] 修改后即时刷新预览。
- [ ] 提供恢复默认设置。
- [ ] 校验页边距，避免正文区域过小。

### Task 6.3：页眉模型

- [ ] 启用或关闭页眉。
- [ ] 左、中、右三栏内容。
- [ ] 页眉字体和字号。
- [ ] 页眉与页面顶部距离。
- [ ] 可选底部分隔线。
- [ ] 支持首页不同。
- [ ] 默认首页隐藏页眉，并允许单独配置。

### Task 6.4：页脚模型

- [ ] 启用或关闭页脚。
- [ ] 左、中、右三栏内容。
- [ ] 页脚字体和字号。
- [ ] 页脚与页面底部距离。
- [ ] 可选顶部分隔线。
- [ ] 首页页码支持单独显示或隐藏。

### Task 6.5：动态变量

- [ ] `{title}` 练习标题。
- [ ] `{subject}` 科目。
- [ ] `{grade}` 年级。
- [ ] `{date}` 日期。
- [ ] `{page}` 当前页码。
- [ ] `{total}` 总页数。
- [ ] 插入变量时提供菜单，不要求教师记忆语法。
- [ ] 未知变量原样保留或明确提示。

### Task 6.6：页眉页脚编辑体验

- [ ] 第一版采用设置面板，而非页面直接双击编辑。
- [ ] 三栏分别输入并显示对齐方向。
- [ ] 支持基础加粗、字体和字号。
- [ ] 显示示例预览。
- [ ] 防止输入危险 HTML。
- [ ] 提供常用模板：无页眉、标题页眉、居中页码、右侧页码。

### Task 6.7：PDF 渲染

- [ ] Playwright 生成动态 header/footer template。
- [ ] 正确注入当前页和总页数。
- [ ] 计算足够的上下边距容纳页眉页脚。
- [ ] 页眉页脚字体资源可用。
- [ ] 首页不同规则生效。
- [ ] 页眉页脚不遮挡正文。
- [ ] 预览和 PDF 使用同一结果。

### Task 6.8：Word 导出

- [ ] 创建 Word 页眉和页脚。
- [ ] 三栏对齐正确。
- [ ] `{page}` 转为 PAGE 字段。
- [ ] `{total}` 转为 NUMPAGES 字段。
- [ ] 首页不同映射到 Word section 设置。
- [ ] 页眉页脚字体和分隔线正确。
- [ ] 页面方向和页边距正确。

### Task 6.9：测试

- [ ] 无页眉页脚。
- [ ] 只有页码。
- [ ] 标题加页码。
- [ ] 左中右三栏均有内容。
- [ ] 首页不同。
- [ ] 横向页面。
- [ ] 极端页边距校验。
- [ ] 多页 PDF/Word 页码检查。

## 2. 本阶段不做

- 不做奇偶页不同。
- 不在页眉页脚中插入复杂表格。
- 不支持任意 HTML。
- 不支持每一页单独不同的页眉页脚。
- 不做水印，除非作为后续独立功能。
- 第一版不支持页眉页脚 Logo。

## 3. 验收标准

1. 教师可以配置页面方向和页边距。
2. 可以设置页眉页脚三栏内容。
3. 页码和总页数正确。
4. 首页不同规则可用。
5. 预览、PDF 和 Word 中页眉页脚内容一致。
6. 页眉页脚不遮挡练习正文。
