## 三、已知问题与失败案例

### 3.1 系统性问题

1. **公式识别缺失**
   - 影响学科：数学（最严重）、化学（中等）、物理（轻微）
   - 当前策略：只标记 `needs_formula`，不尝试识别
   - 建议：接入 Pix2Text 或 UniMERNet 公式识别模型

2. **答案页版式兼容性**
   - 影响：部分试卷答案缺失（物理 3 份、化学 0 份、数学 0 份、英语 0 份）
   - 原因：答案页公式乱码严重，题号与分值括号被拆到不同行
   - 当前策略：列出 `missing_numbers` 供人工处理

3. **英语听力图片边界**
   - 影响：31/396 题卡（7.8%）
   - 原因：图片跨过下一题文字锚点，全宽矩形裁切会切到下一张卡
   - 建议：对图片区域单独检测边界，不与下一题文字重叠

### 3.2 典型失败案例

#### 案例 1：2026 河东英语卷（完全失败）
- **Ground Truth**：82 道编号题（1-82，第 82 题跨两页）
- **程序输出**：0 题
- **原因**：
  - 整卷为扫描图，PDF 无可用文字层
  - 内部对象损坏，大量 xref 错误
  - 当前流水线必须先从 PDF 文字层找到题号，之后才会调用题卡 OCR
- **教训**：扫描版 PDF 需要独立的 OCR 预处理流程，不能依赖原生文字层

#### 案例 2：和平英语卷（修复前失败）
- **Ground Truth**：44 个顶层题卡
- **程序输出**：0 题
- **原因**：PDF 文字层把 `1．（1分）` 拆成了同一视觉行上的六个独立碎片
- **修复**：补充"同一高度碎片重组"兼容逻辑
- **状态**：已修复，重跑成功

#### 案例 3：物理答案页乱码
- **影响**：河北区 Q21、南开区 Q23、红桥区 Q1-10
- **原因**：答案页公式乱码严重，阅读顺序被打乱，题号与分值括号可能被拆到不同行
- **当前策略**：强锚点允许题号出现在行内任意位置，但仍要求题号与分值括号同行
- **建议**：支持跨行锚点匹配（在切块前把相邻行拼接）

## 五、结论与建议

### 5.1 核心结论

1. **题卡切分非常稳定**：除 2026 河东英语扫描卷外，所有 1,063 个题卡的编号、起止位置和跨页衔接均正确，准确率 98.8%。

2. **跨页题拼接可靠**：约 280 个跨页题的纵向拼接和白边收紧均有效，未发现实际截断。

3. **OCR 质量因学科而异**：
   - 物理、英语：可用率高（85-90%），因以文字和简单公式为主
   - 化学：可用率中高（74%），因化学方程式识别良好但表格结构丢失
   - 数学：可用率最低（50%），因分式、方程组、上下标、根号等公式结构大量丢失

4. **答案关联基本可靠**：物理答案匹配率 96%（120/125），缺失的 5 题已列入 `missing_numbers` 供人工处理。

5. **扫描版 PDF 是主要短板**：2026 河东英语卷完全失败，说明当前流水线高度依赖 PDF 原生文字层，无法处理扫描版 PDF。

### 5.2 改进建议

#### 短期（1-2 周）

1. **支持跨行答案锚点匹配**
   - 在切块前把相邻行拼接，解决物理答案页乱码导致的 Q21/Q23 失配
   - 预计影响：物理答案匹配率从 96% 提升到 99%+

2. **英语听力图片边界优化**
   - 对图片区域单独检测边界，不与下一题文字重叠
   - 预计影响：英语题卡完整率从 92.2% 提升到 99%+

3. **扫描版 PDF 预处理流程**
   - 对无文字层的 PDF，先全页 OCR 提取题号，再进入题卡切分
   - 预计影响：可处理 2026 河东等扫描卷

#### 中期（1-2 月）

4. **接入公式识别模型**
   - 推荐 Pix2Text 或 UniMERNet
   - 对标记 `needs_formula` 的题目进行公式识别
   - 预计影响：数学 OCR 可用率从 50% 提升到 75%+

5. **表格结构识别**
   - 接入表格识别模型（如 TableMaster）
   - 预计影响：化学、数学的表格结构可用率显著提升

#### 长期（3-6 月）

6. **建立 Ground Truth 标注体系**
   - 字符级标注，计算 CER（字符错误率）
   - 用于量化评估 OCR 质量，指导模型优化

7. **多模态融合**
   - 将文字、公式、表格、图片统一建模
   - 输出结构化的题目 JSON（含 LaTeX 公式、Markdown 表格等）
