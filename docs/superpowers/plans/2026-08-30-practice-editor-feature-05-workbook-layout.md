# 阶段 5：整册内容编排任务计划

> 状态：待重点讨论  
> 目标：在单题编辑之外，提供整份练习或习题册的轻量编排能力。

## 1. 产品定义

单题编辑解决一道题内部的正确性与清晰度；整册编排解决整份练习的结构、顺序、空白和阅读节奏。

整册编排不是 Word 自由画布，也不是页面任意坐标设计工具。它是一个按从上到下阅读顺序组织内容的流式编排器。

## 2. 推荐页面结构

```text
┌────────────────────────────────────────────────────────────────────┐
│ 练习标题  保存状态      单题编辑/整册编排  页面设置  预览  导出   │
├──────────────┬────────────────────────────┬────────────────────────┤
│ 内容与题目池 │ 整册编排画布               │ A4 真实分页预览        │
│              │                            │                        │
│ + 标题       │ [标题]                     │ 第 1 页                │
│ + 小标题     │ [说明文字]                 │                        │
│ + 文字       │ [第 1 题]                  │                        │
│ + 空白       │ [空白]                     │                        │
│ + 分页       │ [小标题]                   │                        │
│ 题目列表     │ [第 2 题]                  │                        │
└──────────────┴────────────────────────────┴────────────────────────┘
```

## 3. 整册内容模型

练习由按顺序排列的整册内容块组成：

- `title`：主标题。
- `subtitle`：副标题或小标题。
- `instruction`：说明文字。
- `custom_text`：教师自行插入的富文本内容。
- `question_ref`：题目引用块。
- `spacer`：可控空白。
- `page_break`：分页符。
- `section`：结构分组或题型小节。
- `answer_section`：仅作为未来答案功能的结构预留，当前不创建、不编辑、不渲染。

题目引用块指向练习题目快照，不把整道题再次复制到整册文档中。

## 4. 任务清单

### Task 5.1：整册数据模型

- [ ] 新增整册内容块模型。
- [ ] 支持内容块类型、顺序、内容和样式。
- [ ] 题目块保存练习题目快照 ID。
- [ ] 定义章节与内容块的关系。
- [ ] 支持旧章节和题目顺序转换为整册内容序列。
- [ ] 内容块删除和题目删除的规则明确。
- [ ] 题目快照不可因删除显示块而意外丢失，除非用户确认。

### Task 5.2：模式切换

- [ ] 顶部提供“整册编排”和“单题编辑”模式切换。
- [ ] 整册模式点击题目进入单题编辑。
- [ ] 单题编辑提供“返回整册编排”。
- [ ] 模式切换前完成当前保存。
- [ ] 返回整册后保留滚动位置和当前题目位置。

### Task 5.3：左侧内容与题目池

- [ ] 显示可插入内容类型。
- [ ] 显示当前练习题目列表和题型。
- [ ] 支持搜索当前练习题目。
- [ ] 提供从题库或外部题目池继续加题入口。
- [ ] 显示未放入编排画布的题目。
- [ ] 防止同一练习题目被意外重复放入画布。
- [ ] 明确区分“当前练习题目”和“完整题库”。
- [ ] 左侧默认只展示当前练习内容和已选题目。
- [ ] 完整题库通过添加题目弹窗或独立选择界面打开，不常驻左侧。

### Task 5.4：标题与小标题

- [ ] 每份练习只维护一个主标题，主标题由练习设置和整册顶部共同编辑。
- [ ] 禁止重复插入多个主标题。
- [ ] 插入副标题或小标题块。
- [ ] 在画布中直接编辑文字。
- [ ] 设置显示或隐藏。
- [ ] 选择标题级别或预设样式。
- [ ] 支持对齐、字体、字号和间距。
- [ ] 标题样式默认继承全局模板，允许局部覆盖。
- [ ] 支持标题从新页开始。

### Task 5.5：说明文字和自定义内容

- [ ] 插入普通说明文字。
- [ ] 插入教师自定义富文本内容。
- [ ] 支持基础文字和段落格式。
- [ ] 第一版支持公式节点。
- [ ] 第一版支持图片节点。
- [ ] 自定义内容复用单题编辑器的富文本、公式和图片能力。
- [ ] 允许用于考试说明、注意事项、知识提示或分组说明。
- [ ] 自定义内容参与 Word/PDF 导出。

### Task 5.6：题目块

- [ ] 默认显示接近完整的题目内容、题号、题型和修改状态。
- [ ] 长题允许手动折叠，折叠状态只影响编辑界面。
- [ ] 预览和导出始终使用完整题目，不受折叠状态影响。
- [ ] 点击进入单题编辑。
- [ ] 拖动改变题目顺序。
- [ ] 支持删除出当前练习。
- [ ] 删除题目块代表从当前练习删除该题，不引入仅隐藏状态。
- [ ] 支持设置题目前空白和题后空白。
- [ ] 支持设置从新页开始。
- [ ] 支持设置尽量不跨页。
- [ ] 支持设置或覆盖答题留白。
- [ ] 题号由系统根据整册顺序生成，不从单题正文读取。

### Task 5.7：空白块

- [ ] 插入空白块。
- [ ] 提供小、中、大预设。
- [ ] 支持自定义高度。
- [ ] 空白在画布和真实预览中可见。
- [ ] 空白可拖动、复制和删除。
- [ ] 空白跨页时有稳定规则。
- [ ] 区分题后答题留白和纯版面空白。

### Task 5.8：分页符

- [ ] 插入分页符。
- [ ] 画布中清楚显示分页标记。
- [ ] 分页符可拖动和删除。
- [ ] PDF 与 Word 都生成真实分页。
- [ ] 连续分页符自动提示或合并。
- [ ] 分页符不能被一键排版静默删除。

### Task 5.9：拖动排序

- [ ] 标题、文字、题目、空白和分页符均可拖动。
- [ ] 拖动时显示插入线。
- [ ] 支持跨章节拖动。
- [ ] 支持键盘上移和下移。
- [ ] 拖动结束后自动保存顺序。
- [ ] 保存失败回滚到原顺序并提示。
- [ ] 大量题目时保持流畅。

### Task 5.10：轻量整体格式

- [ ] 每个块允许设置前间距和后间距。
- [ ] 标题和小标题允许选择预设格式。
- [ ] 题目允许设置题前、题后空白。
- [ ] 章节允许设置开始新页。
- [ ] 自定义内容允许基础富文本。
- [ ] 不提供任意坐标、重叠和文字环绕。

### Task 5.10A：答案与解析范围控制

- [ ] 当前整册画布不显示答案块和解析块。
- [ ] 当前不提供答案章节或答案册入口。
- [ ] 当前预览和导出只包含练习正文及答题空白。
- [ ] 保留未来题下详解和独立答案册的扩展位置，但不实现界面。

### Task 5.11：预览联动

- [ ] 整册拖动后延迟刷新预览。
- [ ] 编辑标题或空白后刷新对应页。
- [ ] 预览点击某题时可定位到整册画布中的题目，作为可选增强。
- [ ] 真实预览体现分页符和空白。
- [ ] 预览错误不丢失编排修改。

### Task 5.12：测试

- [ ] 插入每种内容块。
- [ ] 混合内容拖动排序。
- [ ] 题目进入和退出单题编辑。
- [ ] 空白和分页符导出。
- [ ] 旧章节迁移。
- [ ] 删除与恢复行为。
- [ ] 大于 50 道题的性能测试。
- [ ] PDF/Word 顺序一致性测试。

## 5. 本阶段不做

- 不做页面元素自由重叠。
- 不做任意坐标拖动。
- 不做多栏复杂版式。
- 不做封面设计器。
- 不做复杂表格排版。
- 不做多人协同编辑。
- 不做答案和解析编排。

## 6. 验收标准

1. 教师可以在整册中插入标题、小标题和自定义文字。
2. 可以拖动题目和其他内容改变顺序。
3. 可以设置题目前后空白。
4. 可以插入和删除分页符。
5. 点击题目可进入单题编辑，返回后位置不丢失。
6. PDF 和 Word 的内容顺序与整册画布一致。
